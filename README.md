# App-Alzhaimer
Prototio de parche IoT para monitoreo remoto de signos vitales y ubicación en pacientes con Alzheimer. Sistema embebido basado en ESP8266 que integra sensor cardíaco MAX30102 (pulso y SpO2), Giroscopio + Acelerometro (MPU-6050) y GPS NEO-6M, con transmisión de datos en tiempo real vía MQTT a una aplicación móvil desarrollada en Flutter.
